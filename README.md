# ShareBite — Vercel-ready static website

## Deploy to Vercel
1. Extract this ZIP file.
2. In Vercel, choose **Add New → Project** and import the extracted folder/repository, or use the Vercel CLI from this folder.
3. No build command or framework preset is required. The site is served from `index.html`.

## Important note
This is the supplied self-contained front-end demo. Its data is stored in the visitor's browser using `localStorage`; it does not use a shared database or server-side authentication. Changes made in one browser/device will not automatically appear for other users. The sample accounts and data are demo-only.
